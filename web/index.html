WeChat Launch Kit / 本地工具

把真实功能，整理成可填写的资料

短入口收集 → 清单校验 → 复制字段。没有账号登录，也不会自动提交。

不联网 · 不自动保存 · 关闭前请导出 JSON
请填写下面的真实资料；空白项会保留为待确认。

01 基础资料

测试号不能当正式账号；普通小程序未必有游戏类目。无需填写密码、AppSecret、身份材料或 AppID。

02 网络与隐私事实

实际处理的数据项（可添加多项）

只按真实处理填写；本地存储不自动排除个人信息，也不自动认定每个分数为个人信息。空白行不生成；删除需点击“移除此数据项”。

受控 API、SDK 和同意流程可在高级 JSON 或 Skill 中补齐。自定义信息在后台有独立入口；不要为最高分勾选微信关系。

03 内容说明

小游戏实践模板：场景 30–800 字符，玩法 50–800 字符，至少 3 项系统，每项 30–800 字符。按当前账号页面复核。

截图与当前页面要求

填写后运行 CLI check-screenshots：默认 3 场景＋3 玩法＋每系统 1 张，60 KiB–5 MiB，PNG/JPG。默认拒绝跨栏目同文件／同像素。不会修改图片来躲避重复。

04 审核后运营素材

按当前后台逐项选择；运营图可为原创设计，真实玩法与授权需人工核对。通用封面模板来自账号页面实践：JPEG、650×250、≤80 KB；其余规格待配置。未选择的栏目不等于平台免填。

此网页不读取媒体文件。导出清单后运行 CLI check-materials 检查实际文件；视频还需 ffprobe。

正式码／体验码与访问验证

05 广告与支付开通资料

广告收入结算与玩家消费支付是两条路线。这里只生成准备清单；不签合同、填证件银行账号、核身或付款。

按所选路线生成的材料清单

可记录“已准备”或“当前页面不要求”与依据，不填证件号码、银行账户或密钥。当前费率、门槛、主体资格与合同按官方页面核准。

06 状态与交付

下列状态必须有外部证据；本工具不会自动提升状态。已提交审核中不等于已上线。

高级 JSON（完整清单）

用于更多系统、数据项、API、SDK、备案状态和截图阈值。先“同步到编辑器”，修改后“应用 JSON”。只在内存处理。

资料检查

校验只核对输入。真实截图、源码行为、声明与平台状态仍须验证。

    官方入口

    后台按当前账号界面进入；没有伪造深链。浏览器受安全策略阻断时停止该路径，改用脱敏截图与手工填写。

    可复制字段

    点击“检查并生成字段”更新。空白或未核实项不会自动补造事实。
